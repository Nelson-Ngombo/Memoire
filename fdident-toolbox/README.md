# fdident toolbox

Quick start

1. Unpack the `fdident` distribution to a directory that is writable by your user (e.g. `Program Files` is not adequate)

2. Open MATLAB

3. `cd` to this directory

4. Run `fdpath` to add all required directories to the path

5. Run `fdtool install` to set up the license

6. Enter the passcode you received from us

7. If installation was successful, run `fdtool`
