This manual describes the basic functionalities of the toolbox, and contains a guide to the backward compatible command-line calls of the functions (compatible with toolbox version 2.0.3, distributed with Matlab 5.x).

Each function also has a new, simple calling form, based on the objects. To learn about these, type 'help <function>' or 'usage <function>' in the command line.

The graphical user interface has its own, built-in helps. Further information is available from http://elecwww.vub.ac.be/fdident/.
